# Свадебный сайт — 17 июля 2027

Одностраничный адаптивный сайт-приглашение. Реализация без сборщика и сторонних JavaScript-зависимостей; готовая статическая production-версия лежит в `dist/`.

## Структура
- `index.html` — HTML, стили и интерактивность.
- `assets/` — фотографии в исходном разрешении, без редактирования.
- `dist/` — опубликованный набор файлов.
- `.openai/hosting.json` — настройки публикации Sites.

Откройте `index.html` или `dist/index.html` в браузере. Шрифты Cormorant Garamond и Manrope загружаются с Google Fonts; предусмотрены системные запасные шрифты.
